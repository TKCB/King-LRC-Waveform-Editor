🖱 鼠标快捷操作

  1. 1. 鼠标滚轮在波形区域可缩放波形；
  2. 2. 鼠标滚轮在歌词区域可滚动歌词；
  3. 3. 歌曲播放时，点击波形图切换当前播放位置；
  4. 4. 歌词条可框选多个，进行拖拽、复制粘贴和删除操作；
  5. 5. 波形区域快速双击，新建歌词条。

⌨ 键盘快捷操作

  1. 1. Ctrl + 鼠标滚轮：可任意位置缩放波形。
  2. 2. 空格：歌曲播放和暂停切换。
  3. 3. Delete：删除选择的歌词条（可删除多条）。
  4. 4. Tab：切换播放速度。
