# King LRC Waveform Editor · LRC 波形编辑器

**在波形上"看见"每一句歌词的时间轴 —— 为 LRC 歌词精确对轨而生的纯前端工具**

纯前端 · 单文件 · 零依赖

</div>

---

## 简介

把音频文件和 LRC 歌词拖进页面，立刻看到与声音对应的彩色波形，每一句歌词化作一张可以自由拖拽的时间卡片。调整歌词时间不再靠"听一句、猜一句"，而是看着波形把时间精确对齐到毫秒。

整个工具就是一个 `index.html`：内嵌全部样式与逻辑，**无任何第三方依赖、无后端、歌词与音频全程留在本地**，打开即用，也方便部署到任意静态空间或 GitHub Pages。

没有音频文件也没关系，首页内置了**示例歌曲**（Web Audio 实时合成），一键生成即可完整体验所有功能。

## ✨ 功能特性

| 分类 | 能力 |
| --- | --- |
| 🎚 音频波形 | 支持 mp3 / wav / ogg / flac / m4a / aac；整曲波形实时绘制；可拖拽播放进度 |
| 🎚 声道视图 | **单声道**（左右合并）/ **双声道**（上下分离显示 L / R）一键切换 |
| 🔍 波形缩放 | 鼠标滚轮在波形区缩放、**Ctrl + 滚轮任意位置缩放**、工具栏 − / ＋ 按钮；实时显示"像素/秒" |
| 📄 LRC 导入 | 拖放或按钮导入 `.lrc` / `.txt`；**音频 + LRC 可一次拖入**自动对齐；带时间标签自动上轨 |
| 📝 纯文本导入 | 无时间标签的整段文字导入后按顺序**均匀铺满**整首歌，再逐个精调 |
| 🎵 播放联动 | 播放时歌词**绿色高亮**跟随；点击波形任意位置即跳转播放；可开启/关闭"跟随播放" |
| 🐌 变速播放 | 0.5x / 0.75x / 1x / 1.5x / 2x 五档变速，慢速精听校准；**Tab 键在 0.5x ↔ 1x 间快速切换** |
| 🎯 时间校对 | 拖拽歌词卡片对时间轴；**框选多条整组拖拽 / 复制粘贴 / 删除**；双击波形快速新建歌词 |
| 💬 双语同轴 | 同一时间点的多行歌词（如中英双语）合并为**一张卡片上下两行**，整体移动不分离 |
| 🏷 标识标签 | `[ti:] [ar:] [al:] [by:] [offset:]` 导入即保存、导出自动保留在文件头部；缺失时自动补空位方便填写 |
| ✂️ 导出 | 导出面板一键**复制到剪贴板**或**下载 .lrc 文件** |
| 📖 歌词编辑 | "歌词编辑"视图以整篇文本方式校对歌词，支持格式高亮提示，**Ctrl + S** 快速应用 |

## 🚀 快速上手

1. 克隆仓库后直接双击 `index.html`（或用任意静态服务器，如 `python -m http.server` / `npx serve`）打开页面；
2. 把 **音频 + LRC** 一起拖入虚线框（或点"选择音频文件"）；
3. 没有现成文件？点「生成示例歌曲」，用示例音频 + 歌词体验完整流程；
4. 双击波形空白处新建歌词条，拖动卡片对齐波形上的鼓点 / 人声起点；
5. 播放试听，微调每一句，满意后点「导出 LRC」。

> 💡 提示：歌词是"先对齐、后精修"的工作流——先拖入纯文本让歌词均匀铺满，再逐个拖动卡片贴到波形上，效率最高。

## 🖱️ 鼠标操作

| 操作 | 作用 |
| --- | --- |
| 滚轮（波形区域） | 缩放波形 |
| 滚轮（歌词区域） | 滚动歌词列表 |
| **Ctrl + 滚轮** | 任意位置缩放波形 |
| 点击波形 | 播放中跳转播放位置 |
| 拖动歌词卡片 | 调整该句歌词时间 |
| 空白处拖框 | 框选多条歌词 |
| 双击波形空白 | 快速新建歌词条 |

## ⌨️ 键盘操作

| 按键 | 作用 |
| --- | --- |
| **Ctrl + 滚轮** | 任意位置缩放波形 |
| **空格** | 播放 / 暂停（在文本输入框内为正常输入空格） |
| **Delete** | 删除选中的歌词条（可一次删除多条） |
| **Tab** | 在 0.5x / 1x 播放速度间快速切换 |
| **Ctrl + C / Ctrl + V** | 复制选中的歌词 → 粘贴到当前播放头时间点 |
| **Ctrl + S** | 在"歌词编辑"视图应用文本框修改 |

## 🏷️ LRC 标识标签

除时间轴歌词外，LRC 文件顶部的标识标签也会被**解析、保留并在导出时置顶**：

| 标签 | 含义 | 说明 |
| --- | --- | --- |
| `[ti:]` | 歌名 | Title |
| `[ar:]` | 歌手 | Artist |
| `[al:]` | 专辑 | Album |
| `[by:]` | 制作 / 编辑 | 歌词制作人 |
| `[offset:]` | 时间补偿值 | 单位毫秒，整体时间偏移 |

导出的文件固定为「标识头 + 空行 + 歌词行」的结构；导入的文件缺少某些标识时，导出会自动补上空标签 `[xx:]`，方便在"歌词编辑"视图中直接填写。
